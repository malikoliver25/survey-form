# Gamer Feedback Survey

A clean, responsive, and semantically structured HTML5 survey form designed to collect insights on player habits, platform preferences, and favorite video game genres. 

## Project Overview

This project is a standalone, interactive form created to gather community feedback from gamers. It implements robust client-side validation to ensure clean data entry for names, emails, and age ranges, utilizing structured HTML5 form controls.

### Features
* **User Details:** Captures standard user information (Name, Email, and Age) with built-in email format validation and age range constraints ($10 - 99$).
* **Platform Preference:** A dynamic dropdown menu to select between PC and Console play.
* **Multiplayer Engagement:** Radio buttons to capture quick binary data regarding multiplayer habits.
* **Genre Tracking:** Multi-select checkboxes tracking player interest across key genres like RPGs, FPS, and Indie titles.
* **Open Feedback:** A custom text area for long-form user comments and suggestions.

---

## Built With

* **HTML5:** Semantic markup, form controls, and native data validation.
